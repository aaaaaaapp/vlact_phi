先看结论

已经实现：从当前图像和语言指令出发，VLM 按顺序自回归预测动作码、再预测物理码；训练与推理都使用两套独立的 token 词表。不是一次性并行输出 72 个 ID。
尚未证明有效：500 步短训的 4 个留出样本里，动作与物理 token 的 teacher-forced top-1 准确率均为 0。较长的 5,000 步续训正在跑，当前不能说已得到可用策略、物理语言或 rollout 成功率。

本阶段是部分 VLM 后训练，不是整套 VLA 全参数训练：视觉编码器与前面的语言层冻结；更新最后 2 层语言层、norm、共享 token embedding/输出头，约 6.006 亿可训练参数。原连续动作扩散头不参与。

方法：输入什么、输出什么

动作流

对 32 步动作 chunk，冻结的 EMA-VQ tokenizer 导出 8 个 ID；每个位置从 K=525 个 <robot_action_i> 中选一个。VLM 的 8 个输出用于离散动作预测；本阶段尚未报告解码后的动作误差或机器人执行结果。

物理流

冻结的空间对齐 EMA-VQ tokenizer 从 17 帧视觉特征变化导出 64 个 ID；每个位置从 K=2048 个 <robot_physics_i> 中选一个。训练标签含未来信息，但 VLM 输入只用当前图像与任务语言，推理不看未来帧。

当前图像 + 任务语言 → Qwen3-VL → A1 … A8 → P1 … P64
                         动作 K525     物理 K2048

固定 72 个输出位置，推理时逐位置约束候选词表并贪心生成。训练使用 teacher forcing 的因果 LM loss，只监督这 72 个目标符号；提示词、padding 和结束符不计损失。动作平均 CE 与物理平均 CE 各乘权重 1 后相加，避免 64 个物理位置淹没 8 个动作位置。

与 PhiZero 相似的是“冻结 tokenizer → 导出离散真值 → VLM 自回归预测”的流程；这里不是 PhiZero 的 256-token/K25000 视频 tokenizer，也没有 Wan 视频重建损失。

数据与训练流程

① 冻结 tokenizer动作 EMA-VQ 8×525；物理空间对齐 EMA-VQ 64×2048，均使用已训 20,000-step 权重。
② 导出 ID在 vlact 环境导出动作、物理目标；按 task / episode / base_index 严格合并。
③ 筛选完整 clip只保留未来帧完整的 469,787 行；固定 episode 留出，防止训练/验证混入。
④ VLM 后训练100k-step Qwen 权重严格加载；扩展 2,048 个物理符号；4 GPU、ZeRO-2。
⑤ 留出诊断先看 teacher-forced CE/准确率，再看真正自回归生成；rollout 尚未做。

5,000-step 作业在运行：先严格加载 100k-step Qwen 基座，再恢复 500-step checkpoint 的 24 个可训练张量；训练优化器重新创建。观察到约 366 / 5,000 步（14:33 静态快照）。第 10 步动作 CE 4.316、物理 CE 7.492；这些仍是训练 batch 数字。该作业的最终 checkpoint 和留出结果尚未产生。

使用 node001 的 GPU 0–3、vlact 环境、DeepSpeed ZeRO-2。预计训练本体约 1.5 小时，之后还需保存与诊断；服务器上其他任务不会被本流程停止或清理。

下一步判定：至少要比较相同留出划分的逐流 CE 与 top-1，增加足够大的跨任务样本 panel，并评估自由生成后的动作解码误差与物理变化重建；若物理 CE/准确率仍无改善，需要复查目标可预测性、时间对齐、输入信息量和训练预算。当前不能比较它与全 VLA 联训或 PhiZero 的下游优劣。
