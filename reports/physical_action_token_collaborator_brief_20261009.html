1. 要解决什么问题

普通视觉语言策略直接从当前图像、指令和状态预测连续动作，能够模仿局部轨迹，但对接触、物体运动和未来结果的表征不足。我们的假设是：让 VLM 先预测短序列的离散动作计划和未来物理变化，再把它们作为连续 action expert 的额外条件，可以提供低频结构与动力学先验，同时保留 Pi/DiT 的细粒度控制能力。

2. 技术设计

  • 动作 token：每个 action chunk 压缩为 4 个位置，每个位置 128 类 EMA-VQ code。
  • Physical Language：PhiZero-aligned 时空 tokenizer 输出 64 个 raw IDs，128 类 codebook；policy 端两两聚合为 32 个 memory positions。
  • 条件融合：action/physics 使用独立 residual attention 与独立 gates，不替换原始 VLM prefix；因此可以显式关闭新增条件回退到 pure Pi。
  • 训练目标：连续 flow/action loss + action-token CE + physics-token CE；tokenizer 固定，部署时使用 VLM free-running predicted token。
  • 公平对照：pure Pi、action-only、joint hard；同一 checkpoint、同一 scene seeds、同一 simulator 和视频校验。

6. 如何解释结果

  • joint > action-only：说明 physics condition 在 action token 之外提供了有效动力学信息。
  • action-only > joint：可能是 physics token 预测误差、物理表示不匹配或 residual gate 学习不足。
  • 两者都低于 pure：说明新增条件造成分布偏移/噪声，不能把 token 作为默认部署模块。
  • pure/action-only/joint 都高：任务接近 ceiling，只能说明兼容性，不能证明增益。

7. 当前判断与下一步

目前最可信的判断是：P64-M32 的工程链路已经打通，训练只更新小型扩展参数；但 rollout 增益尚未成立。下一步应优先完成 seed-file 四任务的 10-seed paired table，并报告每任务有效 episode、success rate、paired wins/losses 和视频复核。若 joint 在已训练任务上仍不超过 action-only，优先做 token predictor calibration、condition dropout 和更成熟的 P256-M8 policy 初始化，而不是继续盲目增加训练步数。
