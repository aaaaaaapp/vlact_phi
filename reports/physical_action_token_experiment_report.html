1. 研究问题与方法

核心假设：离散 action token 表示行为意图，离散 physics token 表示未来物理变化；联合预测两类 token 并条件化 Pi，可以提供可组合的控制中间层。
模块当前设计作用
Action tokenizer4 tokens，vocab 128表示动作模式和行为意图
Physics tokenizer16 temporal transitions × 4 spatial queries = 64 tokens，EMA-VQ K=128表示未来视觉/物理变化
Pi conditioner每 2 个 physics token 聚合，64 → 32 memory tokens给连续动作生成器提供物理条件
Joint predictor预测 4 action IDs + 64 physics IDs在 VLM/reasoner 中联合建模

2. Benchmark、数据与训练预算

  • Benchmark：RoboTwin 八任务：click alarmclock、beat block hammer、open microwave、shake bottle、move playingcard away、pick dual bottles、handover block、place object basket。
  • 原始数据：每任务 50 episodes，共 400 episodes，85,098 clips。
  • 当前训练过滤后：360 episodes、76,109 clips；约 595 steps/epoch（global batch=128）。
  • 正式筛选预算：20,000 optimizer steps，约 33.6 epochs；后续以 5k checkpoint 决定是否截断到 10k 或继续 20k。
  • 正式主结果建议：8 tasks、40/5/5 episode split、50k steps、3 seeds。

6. 结果判定标准与下一步

  1. Joint 必须超过 action-only，才能支持两类 token 联合建模的核心主张。
  2. Predicted physics 应接近 oracle physics，且明显优于 shuffled physics，才能排除未来信息泄漏。
  3. P64-M32 应与 P256-M8、P64-M16 做同预算对照，判断 token 容量是否存在有效区间。
  4. 最终主结果使用至少 3 seeds，报告 mean ± std 和 paired bootstrap/permutation 区间。
  5. 论文先整理实验结果和方法草稿；外部投稿提交前由用户审阅最终版本。
